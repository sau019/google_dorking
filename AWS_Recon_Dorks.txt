# AWS Reconnaissance – Google Dorks

Purpose: Identify potential AWS infrastructure, exposed AWS-related configurations, and publicly indexed credential references during authorized bug bounty reconnaissance.

Replace `example.com` with your authorized target domain.

## 3. Investigation Notes

| Indicator | Possible finding |
|---|---|
| AKIA | AWS access key ID format |
| aws_secret_access_key | Secret credential reference |
| AWS_SESSION_TOKEN | Temporary AWS credential reference |
| amazonaws.com | AWS service reference |
| s3.amazonaws.com | S3 endpoint reference |
| cloudfront.net | CloudFront distribution reference |
| execute-api | API Gateway endpoint reference |
| x-amz- | AWS-related HTTP header or parameter |
